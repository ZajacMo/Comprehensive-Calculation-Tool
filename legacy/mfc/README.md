# 旧版 MFC 实现

本目录是 v1 版本的 MFC（Microsoft Foundation Classes）实现，**仅作历史存档保留**，
不再参与构建，也不再维护。

v2 版本已改用 Qt 6 + CMake 重写，代码位于仓库根目录的 `src/`。

## 为什么保留

- 记录本项目的起点与演进过程，便于对照学习。
- 其中手写的 `point_2` / `point_3` 运算符重载（`综合计算工具.h`）仍是理解
  C++ 运算符重载的好例子。

## 已知缺陷（v1 中已修复的问题）

v2 重写时发现并修复了以下缺陷。它们属于**真实存在的错误**，不是风格问题：

| 文件 | 问题 |
|---|---|
| `EQUATION.h:56,62` | 求根公式写成 `-0.5*(b±√Δ)/c`，正确的应为 `(-b±√Δ)/(2a)`。**所有非平凡二次方程的解都是错的。** |
| `EQUATION.cpp:81` | 顶点式 `a(x-h)²+k` 展开时 `m[1] *= 2*a`，符号应为 `-2*a`。展开结果完全错误。 |
| `Regression_line.h:57-87` | 分页收集数据点时，`(elementnumber-1)%5+1` 与 `elementnumber%5` 混用，当数据点数恰为 5 的倍数时会漏算或多算一个点。 |
| `Regression_line.h:98` | 用 `x == 0 && y == 0` 判定「本行未填」，导致合法的数据点 `(0, 0)` 被当作空行跳过。 |
| `SEPERATER.cpp:60` | 质因数分解用 O(n) 试除，对 10⁹ 附近的素数要循环十亿次，界面长时间无响应。 |
| `TRIANGLE.cpp` | 没有退化检测，三点共线时输出面积 0 却没有任何提示。 |

上述每一项在 v2 中都有对应的回归测试，见 `tests/` 目录。

## 编译 v1（可选）

v1 需要 Visual Studio 与 MFC 组件：

1. 用 Visual Studio 打开 `综合计算工具.sln`
2. 平台设为 x64，编译配置 Release 或 Debug
3. 需要安装「使用 C++ 的最新 v143 生成工具 (x86 & x64)」且勾选 MFC 组件

> 注：v1 的 `.vcxproj` 中的 `My.aps` 是 Visual Studio 的二进制缓存文件，
> 属于生成物，不应纳入版本库。
